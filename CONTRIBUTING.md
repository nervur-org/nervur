# Contributing to nervur

Thank you for your interest in `nervur`.

## Issues are the best way to help

Please open an issue. Bug reports, questions about the documents, and
cases where the library disagrees with [Quo's
spec](https://github.com/razvangherghina/quo) are all welcome, and all
of them are read.

A good report names the version, the engine it ran in, and the smallest
program that shows the behaviour.

## About pull requests

`nervur` is developed in a private repository and published here. Its
design, its layers and its proofs are decided there, and every change
lands with the tests that hold it and with the paragraph of its
specification that it moves.

So a pull request that arrives without discussion usually cannot be
merged as written, however good it is. Please open an issue first and
describe what you would change and why. If we agree on the shape, we
will say so in the issue and take it from there.

This is not a closed door. It is an honest description of how the work
runs, so that nobody spends an evening on a patch that was never going
to land.

## Reporting a disagreement with Quo

Quo is a separate work with its own repository and its own spec. Where
`nervur` and the spec disagree, the spec is right and `nervur` has a
defect. Report it here, and say which sentence of the spec you read.

## Security

Please do not open a public issue for a security problem. See
[SECURITY.md](SECURITY.md).
